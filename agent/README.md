# Training Data Agent

Independent project for automatically building high-quality training data for **deep reasoning, coding and trading**.

## What it does

`discover -> ingest -> normalize -> generate -> validate -> deduplicate -> split`

The collector starts with public arXiv metadata/summaries. More source adapters can be added without changing the dataset format.

If a local Ollama model is available, it generates structured examples. If not, a deterministic fallback keeps the pipeline operational but marks records for review. This separation is intentional: the project does not depend on a local model to collect and organize sources.

## Dataset format

Each accepted record is JSONL with `messages`, `domain`, `source`, and `quality`. Reasoning data uses concise `key_steps`/verification rather than requiring private chain-of-thought. Coding data should ultimately be backed by executable tests. Trading data is educational: concepts, statistics, risk and scenarios; it must not invent returns or present personalized financial advice.

## Domains

- `reasoning`: logic, mathematics, problem solving, scientific reasoning
- `coding`: programming, algorithms, software engineering, debugging, code review
- `trading`: market microstructure, portfolio/risk, econometrics, backtesting

## Important limitations

- The current discovery adapter is deliberately conservative and does not crawl arbitrary websites.
- A source being public does not automatically grant a training license; provenance is stored and license policy should be reviewed before redistribution or commercial training.
- Synthetic examples generated by a small model can contain errors. Use a stronger verifier and executable tests before treating the dataset as production-grade.
- Dataset creation is not model fine-tuning. Fine-tuning is a separate later stage.

## Run

One-time cycle:

```bash
ONCE=1 PROJECT_HOME=$HOME/training-data-agent python3 agent/agent.py
```

Continuous worker:

```bash
systemctl --user status training-data-agent
```

## Fresh VPS

```bash
curl -fsSL https://raw.githubusercontent.com/huyenytmk2912/1/main/install.sh | bash
```

After installation, the worker starts automatically. On VPSes with at least 8 GiB RAM, the installer also offers a small local Qwen model through Ollama; set `MODEL=` to override it.
